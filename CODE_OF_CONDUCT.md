# Code of Conduct

KS ToolBox aims to be a practical, respectful, and welcoming open-source community.

- Be constructive and respectful in issues, pull requests, and discussions.
- Focus feedback on code, behavior, and user workflows — never on individuals.
- Follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) standards.
- Harassment, spam, or abusive behavior will not be tolerated.
