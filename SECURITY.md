# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report security issues privately using **GitHub Private Vulnerability Reporting** under the **Security** tab of this repository.

Include:
- Affected tool and KS ToolBox version
- Operating system and Python / FFmpeg version (if running from source)
- Minimal reproduction steps or sample input

Reports are acknowledged as promptly as possible, and fixes are coordinated before public disclosure.
